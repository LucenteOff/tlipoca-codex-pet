# Tlipoca Codex Pet

通过 ChatGPT 生成的特莉波卡（Tlipoca）Codex 桌宠：白发红瞳、黑红兜帽披风、黑白裙装，以及贴身小幽灵伙伴。

小死神可爱捏~

## 安装

下载 [Tlipoca-pet-v2.zip](outputs/Tlipoca-pet-v2.zip)，解压后将其中的 `Tlipoca` 文件夹放入 Codex 的 pets 目录。

该版本使用 `spriteVersionNumber: 2`，包含标准动画行与 16 个视线方向。

## 生成说明

桌宠根据用户提供的角色半身像与官方 Q 版参考生成，并由 ChatGPT 完成像素化、动画帧、透明图集和 Codex v2 打包。
